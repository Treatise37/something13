Hotkeys

Common keys

  • Tab: Toggle WASD mode
  • Arrow keys: Move
  • Center: Center the map
  • Escape: Return focus to the map and clear the input bar
  • Space (hold): Hold throw mode; release to turn it off
  • Delete: Toggle throw mode
  • F1: Admin help
  • Ctrl+Shift+F1: Options
  • F2: Quick screenshot
  • Shift+F2: Save screenshot
  • F3: Mentor help
  • Ctrl+P: Toggle point mode
  • Alt+C: OOC
  • Alt+L: LOOC

Mouse modifiers

  • Alt+click: Examine
  • Ctrl+click: Pull
  • Middle-click: Switch active hand

Emotes

  • Ctrl+A: Salute
  • Ctrl+B: Burp
  • Shift+B: Toggle resting
  • Ctrl+D: Dance
  • Ctrl+E: Eyebrow
  • Ctrl+F: Fart
  • Ctrl+G: Gasp
  • Ctrl+H: Raise hand
  • Ctrl+L: Laugh
  • Ctrl+N: Nod
  • Ctrl+Q: Wave
  • Ctrl+R: Flip
  • Ctrl+S: Scream
  • Alt+S: Spin (WASD mode)
  • Ctrl+W: Wink
  • Ctrl+X: Flex
  • Ctrl+Y: Yawn
  • Ctrl+Z: Snap

WASD mode

  • W/A/S/D: Move north/west/south/east
  • Q: Drop item
  • E: Equip item in active hand
  • C: Use item in active hand (or move southeast if empty)
  • X: Switch active hand
  • Z: Use item in active hand (or move southeast if empty); repeats southwest while held
  • R: Toggle throw mode
  • F: Fart
  • G: Focus and clear the input bar
  • P: Toggle point mode
  • B (hold): Point; release to stop
  • T: Talk
  • V: Equip item in active hand
  • Alt+T: DSAY (admins)
  • Ctrl+T: ASAY (admins)
  • 0-9: Use ability/action slots 10, 1-9
